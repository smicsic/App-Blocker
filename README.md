# 🧱 App Blocker — система блокировки процессов с защитой от завершения

**Автор:** [@smics_play (Вова)](https://github.com/smicsic)  
**Назначение:** Школы, офисы и личные ПК 🏫💼  

---

## 📝 Описание

**App Blocker** — это защищённая система для мониторинга и блокировки заданных приложений.  
Она не только завершает запрещённые процессы (браузеры, игры, мессенджеры и т.д.), но и защищает **сама себя** от завершения — благодаря связке `AppBlocker.exe` + `SecureSystem.exe`.

---

## 📌 Подходит для

- Контроля рабочего времени сотрудников.  
- Ограничения доступа к развлекательным программам в школах.  
- Родительского контроля на домашних ПК.  
- Любых ситуаций, где нужен **жёсткий контроль над запущенными процессами.**

---

## ⚡ Новые функции (версия 2025)

| Функция | Описание |
|----------|-----------|
| 🔐 **Пароль на выход** | Завершить AppBlocker можно только введя правильный пароль. |
| 🛡 **SecureSystem.exe** | Запускается автоматически и защищает AppBlocker от завершения. |
| ♻️ **Автовосстановление** | Если один из процессов будет закрыт — другой поднимет его снова. |
| 🌐 **Блокировка сайтов** | Новый раздел «Сайты» — добавь домены в блок, и они пропадут через `hosts`. |
| ⏳ **Таймер** | Можно задать время, через которое программа завершит работу. |
| 💾 **Сохранение данных** | Пароль, процесс и настройки запоминаются автоматически. |
| 🧠 **EXIT через config.json** | При корректном выходе AppBlocker пишет статус, который ловит SecureSystem. |
| 🧹 **Автоочистка** | SecureSystem удаляет все служебные файлы после корректного выхода. |
| 🔒 **Перманентная блокировка** | После старта тумблеры защиты и таймера становятся недоступны. |
| 🧾 **Готовые exe-файлы** | Всё работает без Python — просто запускай `.exe`. |

## 🧭 Как использовать

1. 📥 Скачай `AppBlocker.exe` и `SecureSystem.exe` из папки **dist**.  
2. 📂 Размести оба файла в одной папке.  
3. ▶️ Запусти `AppBlocker.exe` **от имени администратора**.  
4. 🔑 При первом запуске задай пароль администратора.  
5. 🧱 Введи имя процесса, который хочешь блокировать (например `chrome.exe`).  
6. 🕵️‍♂️ Нажми **«Начать»** — программа начнёт следить и завершать процесс.  
7. 🚫 Завершить AppBlocker можно только введя пароль.

## 🛠 Если запускаешь из исходников

**Требования:**  
- Python 3.10+  
- Модули: `psutil`, `tkinter`, `pyfiglet`, `customtkinter`

**Сборка в exe:**
```bash
pyinstaller --onefile --noconsole --clean AppBlocker.py
pyinstaller --onefile --noconsole --clean SecureSystem.py
```
